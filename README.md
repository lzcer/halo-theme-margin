# 1. 余白 · Margin

一款简约、专注阅读的 Halo 博客主题，提供留白与纸页两种风格，支持单／双列文章列表、自定义菜单与响应式布局。

以 **Halo 2.20.21** 为兼容目标。站点标题、Logo、favicon、站点描述和全局代码注入沿用 Halo 系统设置。

## 1.1. 功能

- 留白：中性配色、无衬线文字和单纯的阅读层次。
- 纸页：暖色背景、宋体标题与书刊式正文。
- 风格与列表布局独立配置；手机自动变为单列，正文始终为单栏。
- 跟随系统、浅色、深色三种明暗模式。
- 首页、文章、独立页面、归档、分类、标签和错误页面。
- 后台菜单、递归子菜单、父级链接、外链打开方式、移动端折叠与键盘操作。
- 正文目录（顶部、左侧或右侧）、图片点击放大、代码复制、表格横向滚动、评论扩展点、分页与空状态。

## 1.2. 安装

1. 获取 `dist/halo-theme-margin-0.1.2.zip`。从源码构建的方法见第 3 节。
2. 在 Halo 后台进入「外观 → 主题」，上传 ZIP 并启用「余白 · Margin」。
3. 打开主题设置，选择视觉风格和列表布局。
4. 在系统设置中配置站点标题、Logo、描述和 favicon。
5. 在菜单管理中配置主菜单，或在主题设置的「导航菜单」中选择一组菜单。

请上传构建得到的 ZIP，包内根目录应直接包含 `theme.yaml`、`settings.yaml` 和 `templates/`。GitHub 的源码压缩包不是推荐的安装包。

# 2. 配置说明

## 2.1. 外观与首页

| 配置分组   | 设置                                             | 说明                                             |
| ---------- | ------------------------------------------------ | ------------------------------------------------ |
| 外观与布局 | 视觉风格                                         | 留白、纸页                                       |
| 外观与布局 | 列表布局                                         | 单列、双列，手机自动使用单列                     |
| 外观与布局 | 明暗模式                                         | 跟随系统、浅色、深色                             |
| 外观与布局 | 摘要、分类                                       | 独立控制列表中的显示                             |
| 首页介绍   | 标题、正文、引导文字                             | 支持关闭介绍；正文留空使用站点描述或副标题       |
| 首页介绍   | 分类导航                                         | 跳转到 Halo 的真实分类页面                       |
| 文章阅读   | 字号、摘要、目录显示与位置、作者、封面、相邻文章 | 摘要和目录可按需启用；目录可放在顶部、左侧或右侧 |
| 页脚       | 短句、ICP备案号                                  | 留空则不显示                                     |

文章页是否显示封面默认为关闭。目录在存在至少两个二级或三级标题时生成，可放在正文顶部、左侧或右侧；移动端会自动回到顶部。不依赖在线服务。正文图片和封面可点击查看大图，按 Esc 或点击背景关闭。代码复制需要 HTTPS 或 localhost，浏览器不提供剪贴板接口时保留原始代码块。

## 2.2. 菜单

菜单名称、链接、排序、层级和打开方式在 Halo 后台维护。主题设置只选择使用哪组菜单，留空使用 Halo 主菜单。没有配置菜单时不生成虚假的导航入口。

桌面端菜单位于右上角；子菜单使用独立展开按钮，父级名称仍然可以点击。手机上通过「菜单」按钮展开。支持 Enter、Tab 和 Escape。文章、分类、标签等地址使用 Halo 返回的链接，不固定拼接文章路径。

如果希望展示「关于」，请先在 Halo 创建独立页面，再将其添加到后台菜单。多层菜单的内容都可以访问，建议控制顶层菜单数量以保持简约。

## 2.3. 评论与扩展

文章和独立页面保留 Halo 标准评论扩展点，遵循 Halo 的全局评论设置和文章评论开关。需要安装、启用对应评论插件。主题不内置评论服务。

页脚提供 `halo:footer`，全局 head 注入和 SEO 元信息由 Halo 处理。没有额外的主题级代码注入配置。

# 3. 本地开发

## 3.1. 工具

- Node.js 22 或更新版本。
- pnpm 11.19.0。
- 用于联调的 Halo 2.20.21。

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm build
```

主题使用原生 CSS、JavaScript 和 Thymeleaf 模板，不需要前端运行时框架。`pnpm build` 使用 Halo 官方打包工具，输出到 `dist/`。`work/`、开发依赖及本地缓存不进入安装包。

## 3.2. 文件结构

```text
theme.yaml                 主题信息和版本要求
settings.yaml              Halo 后台设置表单
templates/
  index.html               首页
  post.html                文章
  page.html                独立页面
  archives.html            归档
  category.html            分类文章
  author.html              作者文章
  categories.html          分类列表
  tag.html                 标签文章
  tags.html                标签列表
  error/error.html         错误页
  fragments/               公共布局、菜单、列表、分页和页脚
  assets/css/main.css      两种风格、明暗模式和响应式样式
  assets/js/main.js        菜单、目录和阅读增强
```

将主题目录放在本地 Halo 工作目录的 `themes/halo-theme-margin/` 下可进行开发联调。修改 `theme.yaml` 或 `settings.yaml` 后，需要在后台重载主题配置；已有设置值不会因修改默认值而自动覆盖。

## 3.3. 发布前核对

安装生成的 ZIP，分别检查四种风格与布局组合、明暗模式、手机菜单、后台菜单顺序和外链、新旧文章、分类和标签分页、独立页面、评论插件、系统代码注入及错误页。具体本次验证结果见 `docs/validation.md`。
