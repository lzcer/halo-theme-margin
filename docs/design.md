# 1. 余白主题设计

面向 Halo 2.20.21，依据已确认的文章列表与正文预览实现。主题包名称为 `halo-theme-margin`，站点名称、Logo 和站点描述来自 Halo 系统设置。

## 1.1. 外观与布局

留白采用中性背景、无衬线字体与细分隔线；纸页采用暖色背景、宋体标题和书刊式排版。风格与列表布局独立配置，支持四种组合。手机端统一为单列，文章正文始终保持适宜阅读的单栏宽度。

明暗模式提供跟随系统、浅色和深色。使用本机字体，不请求外部字体服务。

## 1.2. 内容与导航

服务端 Thymeleaf 模板渲染真实文章、摘要、分类、标签与分页。所有内容链接使用 Halo 返回的 permalink。导航默认读取主菜单，也可在主题设置中选择其他菜单；递归渲染菜单树，尊重后台顺序和打开方式。父级链接与展开按钮分开，手机导航复用同一棵菜单树。

支持首页、文章、独立页面、作者、归档、分类、标签与错误页。正文保留原始内容 HTML，提供目录、代码复制、表格横向滚动，并保留 Halo 评论与页脚注入扩展点。

## 1.3. 工程与验证

使用原生 CSS 和 JavaScript，不引入运行时前端框架。使用官方主题打包工具生成安装 ZIP。检查格式、JavaScript 语法、模板渲染、配置默认值、响应式布局及导航交互。运行环境验证与纯浏览器检查在交付说明中分别记录。
