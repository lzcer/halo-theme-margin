# 1. 发布核对清单

本文是固定的检查指南，不是更新日志或某个版本的验证结果，无需逐版本填写。Release 更新说明由 Git 提交记录自动生成。

## 1.1. 自动执行

标签发布工作流会执行：

- 校验标签符合 `v<SemVer>` 格式，例如 `v0.1.10`。
- 从标签取得版本，同步到构建目录的 `package.json` 和 `theme.yaml`。
- 按锁文件安装依赖，检查 JavaScript 语法与 Prettier 格式。
- 打包主题，上传 ZIP，并从 Git 提交记录生成 Release 说明，仅收录 `feat`、`fix`、`perf`、`style` 类型，支持作用域和 `!` 标记。

这些检查不包含实际 Halo 安装、浏览器页面或插件联调。

## 1.2. 页面与配置

涉及页面或配置变化时，按影响范围检查：

- 留白、纸页、淡雅、像素风格以及单双列、明暗模式。
- 桌面与手机布局，较长标题、空列表和分页。
- 后台菜单顺序、层级、父级链接、外链和手机展开操作。
- 首页介绍、分类 Tab 和文章摘要开关。
- 文章目录层级、顶部／左侧／右侧位置和手机布局。
- 图片预览、滚轮缩放、拖动、手机双指缩放。
- 代码块、复制按钮和宽表格。

## 1.3. Halo 联调

- 在兼容的 Halo 版本中上传 Release 的主题 ZIP，确认可安装或升级。
- 保存主题配置后检查前台变化及静态资源版本。
- 检查真实文章、独立页面、分类、标签、归档和错误页。
- 涉及插件时，检查评论、代码复制、全局注入及插件页面。
- 部署在反向代理后时，检查资源、图片和页面链接。
