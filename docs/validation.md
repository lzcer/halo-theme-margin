# 1. 验证记录

0.1.9 新增「像素」视觉风格。本次执行静态检查、打包、使用示例数据的模板渲染与浏览器验证。第 1.3 节 Halo 联调记录来自此前开发阶段，不代表本次版本已在真实 Halo 后台完成升级和配置验证。

## 1.1. 静态检查

- 修改文件已使用 Prettier 格式化。
- `pnpm check` 通过，主题 JavaScript 通过 Node.js 语法检查。
- `pnpm build` 通过，生成 `dist/halo-theme-margin-0.1.9.zip`。
- 安装包检查通过，ZIP 根目录包含 `theme.yaml`、`settings.yaml`、`templates/`，不包含 `node_modules`、`.git`、`.pnpm-store` 或 `work`。
- `git diff --check` 通过。

## 1.2. 模板与浏览器检查

- 使用 Thymeleaf 3.1 和 Spring 表达式渲染四种风格、单列／双列的首页、文章、独立页面、作者、分类、标签、归档和错误页，共 80 组组合；另渲染 10 组像素风配置变体。
- 使用 Microsoft Edge 检查首页与文章页在 1440、768、390 和 320 像素宽度，以及浅色、深色和跟随深色系统的组合，共 192 组；无横向溢出和 JavaScript 运行错误。
- 另完成 40 组像素风检查，涵盖首页介绍、分类 Tab、文章摘要和目录关闭，以及目录位置、长中文标题、英文点阵字标。目录在窄屏回到正文上方，关闭分类 Tab 显示静态“最新文章”。
- 核对像素风跟随浅色、深色系统时的背景配色，查看桌面首页、正文与手机深色截图。
- 验证像素风手机菜单、三级菜单和 Escape 关闭，并核对目录链接数量及代码块渲染。
- 图片手势、插件复制按钮、评论、生产文章数据及后台配置保存不属于本次浏览器验证范围。
