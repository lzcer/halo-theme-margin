# 1. 验证记录

0.1.8 新增「淡雅」视觉风格。本次执行静态检查、打包、使用示例数据的模板渲染与浏览器验证。第 1.3 节 Halo 联调记录来自此前开发阶段，不代表本次版本已在真实 Halo 后台完成升级和配置验证。

## 1.1. 静态检查

- 修改文件已使用 Prettier 格式化。
- `pnpm check` 通过，主题 JavaScript 通过 Node.js 语法检查。
- `pnpm build` 通过，生成 `dist/halo-theme-margin-0.1.8.zip`。
- 安装包检查通过，ZIP 根目录包含 `theme.yaml`、`settings.yaml`、`templates/`，不包含 `node_modules`、`.git`、`.pnpm-store` 或 `work`。
- `git diff --check` 通过。

## 1.2. 模板与浏览器检查

- 使用 Thymeleaf 3.1 和 Spring 表达式渲染留白／纸页／淡雅、单列／双列的首页、文章、独立页面、作者、分类、标签、归档和错误页，共 60 组组合。
- 使用 Microsoft Edge 检查首页与文章页在 1440、768、390 和 320 像素宽度，以及浅色、深色和跟随深色系统的组合，共 144 组；无横向溢出和 JavaScript 运行错误。
- 核对淡雅在浅色、深色和跟随系统模式下的背景配色，检查桌面首页、正文截图。
- 验证淡雅手机菜单、三级菜单和 Escape 关闭，并核对目录链接数量及代码块渲染。
- 图片手势、插件复制按钮、评论、生产文章数据及后台配置保存不属于本次浏览器验证范围。
